# APX Documentation History

This directory preserves historical engineering evidence without mixing it with current documentation.

## Categories

### Audits

Historical repository, retrieval, evidence, freshness, and status audits.

### Phase reports

Completed phase verification and implementation reports from the APX V1.1 / Phase 6 progression.

### Build briefs

Historical implementation contracts and phase-specific build instructions.

## Reading historical material

Historical reports may contain:

- superseded architecture assumptions;
- benchmark results from older datasets;
- intermediate defects that were later repaired;
- target metrics;
- incomplete/in-progress findings.

Therefore they should be interpreted together with the current documentation under `docs/`.

## Important supersession rule

The repository contained two retrieval forensic audit files with the same title. The incomplete `APX_RETRIEVAL_FORENSIC_AUDIT.md` was superseded by the completed `APX_RETRIEVAL_FORENSIC_AUDIT(1).md`. The completed report is retained in the archive under the canonical filename `APX_RETRIEVAL_FORENSIC_AUDIT.md`; the incomplete duplicate is removed.

No historical report is deleted merely because it is old. The goal is to preserve the engineering trail while keeping the active documentation navigable.
