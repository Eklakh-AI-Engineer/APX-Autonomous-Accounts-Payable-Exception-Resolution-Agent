**Evaluator-contract finding:** The 500-case dataset provides expected decisions, but no independently reviewed expected-action, expected-guardrail, or expected-approval labels. The action evaluator maps expected decisions to expected action types and derives expected guardrail/approval values from that mapping plus the pipeline risk assessment. Benchmark rows do not attribute the 252 unsuccessful attempts to ERP responses or adjudicated operational causes. The 498/500 case union is overlap-aware; it does not imply 498 independent root causes. A valid acceptance rerun requires independently authored policy labels, reviewer/adjudication provenance, and case-linked source invoice/job records.

## Verified evidence and limits

The new normalization is defensive but does not change this benchmark distribution. The candidate adds a direct regression using a plain non-string Enum (so string-enum equality cannot mask the issue); it passes CI #91/#92.
